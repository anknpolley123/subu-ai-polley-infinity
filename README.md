# 🤖 Subu AI — Polley-Infinity

### A Futuristic AI Assistant Interface

Subu AI (Polley-Infinity) is a web-based assistant interface created by **Ankon Polley**. The repository currently contains a basic chat UI built with HTML, CSS, and JavaScript.

> **Project status:** The current JavaScript provides a simulated demonstration response. A real AI model/API integration has not been verified in this repository.

---

## ✨ Features

- 💬 Chat-style user interface
- 🎨 Futuristic dark design
- 🖼️ Project logo and branding
- 🌐 HTML, CSS, and JavaScript frontend
- 🔥 Firebase Hosting configuration files

### Current limitations

The current version is a frontend prototype. Do not assume it includes a connected AI model, persistent chat history, authentication, or a native Android application unless those features are implemented separately.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/anknpolley123/subu-ai-polley-infinity.git
cd subu-ai-polley-infinity
```

### Run locally

Open `index.html` in a modern browser.

Alternatively, if Python is installed, run a local web server:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

Running the frontend locally does not connect it to an AI model.

---

## 🔥 Firebase Hosting

The repository contains Firebase configuration files. To deploy, configure a Firebase project and review the existing `firebase.json` and `.firebaserc` before deploying.

Typical commands when Firebase Hosting is configured:

```bash
firebase login
firebase deploy
```

See the [Firebase Hosting documentation](https://firebase.google.com/docs/hosting). Firebase Hosting by itself does not provide AI model functionality.
